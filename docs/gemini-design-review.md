## 1. 現行実装の精査：AIサイト（ChatGPTの悪癖）に見えていた理由

### 見た目・レイアウトの問題
1. **ロゴを大きく置いただけで中身が伝わらないヒーロー（FV）**
   - `hero-visual` に `logo-dark.svg` を大きく配置しただけで、イベントの3要素（星空解説・キャスト接客・歌唱ライブ）や90分間の構成が視覚的に伝わらなかった。
   - ロゴの背後に `.orbit-mark` の二重楕円線を描画していたため、ロゴ自体の軌道リングと無意味に干渉していた。
2. **重い暗色ダッシュボード的な均一感**
   - 公開HP（`#0b1025` / `#11182e`）とポータル（`#10131c` / `#171b25`）が同じ暗色管理画面の配色で、イベントとしての華やかさや可愛さ、親しみやすさが欠けていた。
   - どのセクションも「1pxの細い枠線＋同じ角丸（12px）の箱」または「細い区切り線リスト」の反復で、視覚的なメリハリがなかった。
3. **2段構えの間延びしたヘッダー**
   - PCヘッダーが上下2段（高さ140px）を占め、下段の6リンクを `justify-content: space-between` で横幅いっぱいに離していたため視線移動が長く、Xリンクもテキスト文字 `X` のみでボタンとして認識しづらかった。
4. **二重枠・不揃いな間隔**
   - 運営ページの `.panel` 内に点線枠の `.empty-inline` が入り、二重枠になっていた。
   - ボタン内の矢印との間隔（`gap: 24px` や `16px`）が広すぎて文字と矢印が離れていた。

### 文章・情報設計の問題
1. **無意味な飾り英語ラベルの連発**
   - 全セクションの見出し上に `Schedule` / `Cast` / `About` / `News` / `Social` を機械的に並べていた。
2. **事務的・反復的な「準備中」案内**
   - 営業情報・キャスト・お知らせ・動画のすべてで「準備中です」「公開までお待ちください」が同じ調子で繰り返されていた。
3. **硬い・冗長なUI文言**
   - 「このページでは、あなた宛てのチェキを表示します。」など回りくどい前置きや、矢印記号のテキストべた書きが目立っていた。

## 2. 新しいデザイン方向性

1. **カラー設計（濃紺ベース＋ロゴ由来の明るいポップアクセント）**
   - 背景は深い夜空の紺（`#0f1535` / `#141c44`）、カード面は視認性の高い紺（`#192252`）へ調整。
   - `public/assets/logo-dark.svg` に含まれる色から **クリームゴールド（`#ffe09e`）**・**ラベンダー（`#cbb8ff`）**・**パステルピンク（`#f6bfd5`）** を抽出し、チップ、プログラムカードのアクセントライン、会員ページバナー（`#cbb8ff` 背景＋濃紺文字 `#13193b`）に明快な差し色として配置。
   - 無意味な虹色グラデーション、発光（glow）、ネオン枠は使わず、単色の面と大きな角丸（`20px`〜`28px`）で可愛さと読みやすさを両立。
2. **タイポグラフィと文字サイズのメリハリ**
   - 丸みと親しみやすさのあるゴシック体スタック（`Hiragino Maru Gothic ProN`, `BIZ UDPGothic`, `Yu Gothic UI`）を軸に、見出しサイズ差（`h1: clamp(32px, 3.8vw, 50px)`, `h2: 30px`, 本文 `16px`）と行間を整えた。
   - キャッチコピーは指定通り「今宵、星降るドームで<br>夜想曲を。」を維持。
3. **親しみやすい見出しと自然な日本語**
   - 飾り英語 `Schedule` / `Cast` / `About` 等を廃止し、「次回の営業情報」「在籍キャスト」「のくぷらの楽しみ方」などの見出し＋短い補足文（`.section-lead`）に統一。
   - 管理用・実装用語や仮データ・架空イベントは一切追加せず、未登録項目は正直に準備中として案内。

## 5. 公開前の追加確認・ユーザー指定の反映

- スマホでポータルのログアウト・運営ページへのボタンが隠れないよう、非表示指定を公開HPのヘッダー内だけに限定。
- タブレット幅ではナビを折りたたみ、横にはみ出さず操作できるよう調整。
- 提供された横長SVGを公開HPのヘッダーとフッターへ採用し、イベント名の別テキストを削除。
- イベント種別のラベルから背景・枠を取り、指定キャッチコピーは改行せず1行表示。
- ヒーローの写真部分は角のある額縁へ変更。管理画面のトップ画像を登録すれば集合写真に差し替え可能。写真全体が収まる表示とし、未登録の間は提供ロゴを表示。
- 冗長な準備中案内を短縮し、サイト上のチェキ閲覧と保存先Driveの管理者による管理の違いを明記。
- 検証用プレビューに `--populated` を追加。キャスト・お知らせ・固定ページ・マニュアルがある状態を、本番データを使わず確認可能にした。
- キャスト詳細、記事、会員、出欠フォーム、マニュアル、運営の記事編集を確認。認証・所属・ロール・画像権限などのバックエンド処理の変更なし。

- 追加指定により「のくぷらの楽しみ方」の小見出し文を削除。本文に略称「（のくぷら）」を追加。
- プログラムはカード形式から横罫線の縦3行へ戻し、Geminiが選んだフォント・文字サイズの方向性を維持。

- SNSはX・YouTubeのロゴに変更。両リンクと動画の上端をそろえ、上部メニューにもYouTubeを追加。取得データがない場合でも既知の公式リンクを表示する。
- 会員バナーは「会員ページ」「会員ページへ」に整理し、営業情報右上の開催ペースの重複表示を削除。
- お気に入りは宣材写真・名前を横3列で並べ、複数選択・保存を維持。写真がない場合は提供ロゴを表示。チェキ案内は「キャストから」に変更。
- ユーザー指定により、公開HPの説明を「直径24mのプラネタリウム」に統一。

- 最終追加指定：お気に入り欄はPCで横6列、タブレット・スマホで横3列。公開キャスト一覧と詳細のリンク文言は「お気に入りキャストに登録」に統一。
